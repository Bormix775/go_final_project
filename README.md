# Описание проекта

Веб-сервер на Go для ведения списка дел. Позволяет создавать задачи, просматривать их список, редактировать, удалять и отмечать выполненными
Для повторяющихся задач автоматически вычисляется следующая дата (правила `d`, `y`, `w`, `m`). Данные хранятся в SQLite

# Задания со звёздочкой

Выполнены:
поиск задач по подстроке и по дате
правила повторения по дням недели 
сборка докер-образа и запуск контейнера с базой данных
 
 ## Запуск локально

Требуется Go 1.26

Переменные окружения:
`TODO_PORT` — порт сервера (по умолчанию `7540`)
`TODO_DBFILE` — путь к файлу базы (по умолчанию `scheduler.db`)
`TODO_PASSWORD` — пароль; если задан, доступ к API требует аутентификации

Пример запуска с паролем
`bash`
`TODO_PASSWORD=12345 go run main.go`
